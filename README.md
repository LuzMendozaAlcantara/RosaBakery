# 🍰 Menú Web Interactivo para Pastelería Artesanal

## El Proyecto
Desarrollé una página web dinámica y atractiva para un emprendimiento real de pastelería. El objetivo principal fue crear una experiencia súper amigable para que los clientes pudieran tentarse con los postres y armar su pedido de forma rápida y sencilla, sin que la página se trabe o tenga que recargar.

## Lo que logré en esta app:
*   **Vitrina Digital:** Un catálogo de postres visualmente atractivo donde cada producto luce increíble.
*   **Carrito Inteligente:** Creé un panel lateral interactivo (que se desliza al hacer clic) donde el cliente puede ir viendo lo que eligió, sumar o restar postres, y ver el precio total actualizándose al instante.
*   **Experiencia Fluida:** Logré que toda la página esté conectada. Cuando tocas "Agregar" en un pastel, el carrito lo sabe inmediatamente, dándole al cliente una sensación de que la app es moderna y rápida.

## Las herramientas que usé (Mi Stack):
*   **React:** Construcción de la página mediante componentes interactivos y reutilizables.
*   **Context API:** Sistema global de gestión de estado (`CartContext`) para controlar la memoria del carrito.
*   **CSS Modules:** Estilos modulares (`styles.module.css`) para crear un diseño a medida y asegurar que se vea perfecta tanto en computadoras como en celulares sin conflictos de CSS.
*   **Vite + JavaScript (ES6+):** Entorno de desarrollo para carga rápida y uso intensivo de características modernas como desestructuración, arrow functions y métodos de arrays (`map`, `reduce`).

## Cómo ejecutar este proyecto localmente
1. Clona el repositorio.
2. Ejecuta `npm install` para instalar las dependencias.
3. Ejecuta `npm run dev` para levantar el servidor de desarrollo.
